# baley.ai

Source for https://baley.ai, the public page for Baley (https://github.com/crenshawdev/baley).

One static page, no build step, no scripts, no third-party requests. Served by Cloudflare as a Worker with static assets. The typeface is EB Garamond, self-hosted under the SIL Open Font License (public/fonts/OFL.txt).

Deploy with `npx wrangler deploy`.
